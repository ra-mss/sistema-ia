# Sistema de IA

Proyecto de practica para la materia Arquitectura 
de Sistemas de Inteligencia Artificial.

## Componentes

- Modelo
- Inferencia
- Configuracion
- Documentacion

## Descripción 
Construir un sistema de IA capaz de colaborar en tareas relacionadas con ingeniería de software.

## Objetivo
Investigar e implementar cómo un agente puede conectarse a capacidades externas mediante Model Context Protocol. Además, el sistema deberá dividir problemas complejos entre diferentes roles, workflows o agentes
especializados.

## Componentes principales
- Agentic Systems.
- Multi-Agent Architectures.
- MCP.
- Tool Calling.
- Coordinación.
- State.
- Memory.
- Human-in-the-Loop.
